## Run the Portfolio Locally

You can clone this repository and run the portfolio on your own computer.

### Prerequisites

- Node.js compatible with the Vite version specified in the project.
- pnpm compatible with the workspace configuration.
- Git.

### 1. Clone the repository

```bash
git clone https://github.com/s-gowtham-reddy/PORTFOLIO-.git
cd PORTFOLIO-
```

### 2. Install dependencies

From the repository root:

```bash
pnpm install
```

### 3. Configure the environment

The Vite configuration uses `PORT` and `BASE_PATH`. Set these variables in your terminal before starting the application.

**Windows PowerShell**

```powershell
$env:PORT="5173"
$env:BASE_PATH="/"
```

**macOS / Linux**

```bash
export PORT=5173
export BASE_PATH=/
```

### 4. Start the development server

From the repository root:

```bash
pnpm --filter @workspace/gowtham-portfolio dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Build the portfolio

To create a production build of the portfolio application:

```bash
pnpm --filter @workspace/gowtham-portfolio build
```

The generated static assets are written to:

```text
artifacts/gowtham-portfolio/dist/public/
```

For a production build, set `VITE_SITE_URL` to the public website origin so the sitemap can be generated with the correct URLs.

> **Note:** The development and build commands above target the portfolio application rather than unrelated workspace packages. The existing workspace also includes supporting server and shared-library packages; these are not necessarily required to render the portfolio website itself.
